# Исправить область изменений при экструзии по готовой сетке кривых

Репозиторий назначения: https://github.com/ONEGOCH/CoreSolution
Задача: https://github.com/ONEGOCH/CoreSolution/issues/327
Ветвь реализации: `codex/327-fix-curve-mesh-change-scope`.

При генерации многопроходного шва Simmax с OperationalController 4.10.8 возникает `InvalidOperationException: Change scope is not active.` Четыре публичных метода экструзии вызывают регистрацию изменений без активной области. К моменту исключения объёмный набор и узлы уже добавлены; операция и уведомление клиента не завершены.

Основание: исследование SeamExtrusionChangeScopeReport.md от 14.10.2026, включая анализ IL пакета 4.10.8. Доступный checkout ядра не является доказанным исходным деревом опубликованного пакета.

## Реализация

- Открыть `using (BeginChanges())` в обеих перегрузках `ExtrudeElement3DAlongCurveMesh`, в `ExtrudeElement3DAlongCurveMeshAdjusted` и `ExtrudeElement1DAlongCurveMesh`.
- Для Adjusted включить создание объёма и оба слияния узлов; проверку допуска оставить перед областью.
- Для 1D включить добавление узлов и Beam-набора.
- Исправить комментарий RegisterChange согласно обязательной активной области.
- Добавить регрессионные проверки и обновить документацию контроллера.

Сохранить алгоритмы, команды мастера, режимы transfinite и допуск слияния. Область изменений не выполняет откат модели.

## Критерии приёмки

- [ ] Все четыре API создают ожидаемые элементы на минимальной геометрии с готовой сеткой кривых без исключения области.
- [ ] Проверены оба режима transfinite для 3D.
- [ ] Подписчик получает один итоговый пакет и видит завершённое слияние узлов.
- [ ] 1D создаёт Beam-набор и уведомления об узлах и наборе.
- [ ] После ошибки входных данных корректная операция публикует события.
- [ ] Собраны затронутые проекты и выполнены релевантные тесты; устаревший TestModel исключён.
- [ ] Обновлены диаграммы и итоговый PDF контроллера.
- [ ] Исправленная библиотека подключена в Simmax новой версией пакета либо явной ссылкой на исходники; проверена фактически используемая DLL.
- [ ] На заново открытом исходном проекте проверен полный мастер: объём, группа, траектория, опорная линия, источник нагрева, несколько проходов и швов.

Выпуск пакета и проверка GUI — интеграционный этап: изменение CoreSolution само по себе не обновляет пакетную DLL Simmax.
