# Бизнес задачи BazisCORE

BazisCORE обеспечивает единую программную основу инженерного моделирования - это логическое ядро.


Его основная бизнес-задача — снижение стоимости разработки и сопровождения инженерного ПО за счёт повторного использования операций с моделями, физическими данными и результатами.



Непосредственные потребители — разработчики CAE-приложений и специализированных инженерных инструментов. 



Бизнес-ценность ниже сформулирована как ожидаемый эффект возможностей решения; количественные показатели экономии не установлены.



## Задачи и практическая ценность

|Бизнес-задача|Как CORE её решает|Практическая ценность|
|-|-|-|
|Повторно использовать инженерную функциональность в разных приложениях|Предоставляет библиотеки геометрии, сетки, условий задачи, материалов и результатов|Позволяет создавать новые приложения без повторной разработки базовых операций|
|Сократить трудоёмкость подготовки расчётной модели|Обеспечивает операции с геометрией, генерацию и редактирование сетки, создание групп и назначение условий|Автоматизирует подготовку данных для расчёта|
|Обеспечить единообразное хранение инженерных данных|Связывает модель, материалы, физические условия и параметры задачи в проекте|Упрощает сохранение, повторное использование и передачу проекта|
|Автоматизировать подготовку последовательности расчётов|Препроцессор формирует инструкции по условиям задачи и временным этапам|Сокращает ручную подготовку входных файлов и связывание физических расчётов|
|Подготовить результаты к анализу и обмену|Хранит результаты, строит поля и цветовые шкалы, экспортирует данные|Позволяет использовать результаты в разных клиентах и последующей обработке|

Основание: [архитектура CORE](Documents/Architecture.md), [препроцессор](PreProc/Documents/PreProc.md), [постпроцессор](PostProc/Documents/PostProc.md).

## Границы текущих возможностей

Формирование расчётных инструкций в текущем пути `CalcCompDataV2` реализовано для тепловой, механической и связанной термомеханической задачи. Химическая ветка в этом пути закомментирована. Полноценная гидродинамическая задача требует расширения контрактов. Наличие структур хранения физических полей не означает готовую поддержку всех четырёх физических направлений.

Основание: [реализация PreProc](PreProc/PreProc.cs), [реестр расхождений](Documents/ArchitectureDifferences.md).

CORE предоставляет подготовку данных и обработку результатов. В составе рассмотренного GUI численный расчёт выполняет внешний решатель: [запуск расчёта](../../Gerbera/GUI/Methods/Comp/StartStopConp.cs).

## Краткое описание продукта

Платформа для разработки инженерных приложений, обеспечивающая подготовку расчётных моделей, управление физическими данными и обработку результатов.
